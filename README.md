# 📊 Dashboard de Salários na Área de Dados

Este projeto é um dashboard interativo desenvolvido com [Streamlit](https://streamlit.io/) que permite explorar dados salariais de profissionais da área de dados ao redor do mundo. Através de filtros dinâmicos e visualizações intuitivas, é possível analisar tendências salariais por cargo, senioridade, tipo de contrato, tamanho da empresa e localização.

## 🌐 Acesse o Dashboard Online

🔗 [Clique aqui para visualizar o dashboard](https://salarios-data-2025.streamlit.app/)

## 🚀 Funcionalidades

- Filtros interativos por ano, senioridade, tipo de contrato e tamanho da empresa
- Métricas principais (salário médio, máximo, cargo mais frequente, total de registros)
- Gráficos dinâmicos com [Plotly](https://plotly.com/python/)
  - Top 10 cargos por salário médio
  - Distribuição de salários
  - Proporção de trabalho remoto vs presencial
  - Mapa de calor com salários de Cientistas de Dados por país
- Tabela detalhada com os dados filtrados
